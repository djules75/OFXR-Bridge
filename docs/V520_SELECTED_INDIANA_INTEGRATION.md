# V520: accepted Indiana branch merged after V519

V520 merges the accepted original Indiana V701 delta into V519, after the
owner-selected clean main-line export through V513 and the KCD integration.
It adds packed D24/S8 depth transport/low24 UNORM decoding and the original
OptiScaler native view-row convention for Indiana camera histories.
KCD temporal-span ownership, DOOM camera interpretation, and V512/V513 marker
optimizations remain present. Functional AFW still uses mandatory depth-aware
native subtraction and same-eye reconstruction in Normal motion mode.

Original V701 was accepted by the owner for Indiana. V520 is a new combined
DLL; its game/headset validation remains pending. KCD distant-tree wobble is
still reported and is not reclassified by the merge. No additional FPS gain,
HUD exclusion or all-game acceptance is claimed.

HUD V514-V518 source/ancestry/artifacts and the local failed mock-director
fixture experiment remain excluded. Original numbered tags and packages are
unchanged. The V513 default CPU mock director fixture clears its session registry
before actual EndFrame dispatch and remains documented/excluded from applicable
integration checks. Real GPU director/ownership checks are retained.

The private release ships the merged V520 ZIP, exact source archive, checksums,
build/validation provenance and the unchanged accepted original V701 ZIP.
No public export, live installation, registration, tray activation or game INI
change is performed as part of publication.
